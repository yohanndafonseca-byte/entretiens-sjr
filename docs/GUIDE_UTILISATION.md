# Guide d'utilisation – Entretiens professionnels

Ville de Saint-Jean-de-la-Ruelle · Direction des Ressources Humaines

---

## 1. Le principe en une minute

Chaque agent a **un dossier par campagne** (une campagne = une année). Le dossier suit toujours le même circuit :

```
① Le N+1 rédige le compte rendu  →  ② le N+1 vise
③ L'agent vise (prise de connaissance + observations)
④ Les supérieurs visent dans l'ordre : N+1, N+2, … jusqu'à la DGS
⑤ L'agent vise une dernière fois  →  compte rendu DÉFINITIF
   → PDF envoyé par e-mail à l'agent + disponible pour l'archivage
```

À chaque étape, la personne qui doit agir reçoit un e-mail. Si elle ne fait rien pendant quelques jours (5 par défaut), elle est **relancée automatiquement**.

**Se connecter** : adresse de l'application, puis **matricule + code personnel**. À la première connexion, on remplace le code remis par les RH par son propre mot de passe.

---

## 2. Agent

1. Quand c'est à vous, le dossier apparaît dans **« À traiter »** (et vous recevez un e-mail si vous avez une adresse).
2. Lisez le compte rendu. Vous pouvez télécharger le PDF.
3. Écrivez vos **observations** si vous le souhaitez, cochez **« J'ai pris connaissance »**, puis cliquez sur **Viser**.
4. À la fin du circuit, vous visez une **dernière fois** : ce visa vaut notification. Le PDF définitif vous est envoyé.

> Viser ne veut pas dire être d'accord : c'est la preuve que vous avez lu le document. Les voies de recours sont rappelées à la fin du PDF.

**Pas d'ordinateur ni d'e-mail ?** Deux possibilités :
- votre responsable vous fait viser **sur son poste** : vous tapez vos observations et votre **code personnel** ;
- vous signez la **version papier**, et les RH enregistrent votre visa.

---

## 3. Responsable direct (N+1) – rédaction

1. Ouvrez le dossier depuis **« À traiter »**.
2. Le formulaire reprend votre modèle habituel (parties I à VI). **La partie I contient déjà les objectifs fixés l'an dernier** : il reste à indiquer le résultat.
3. Tout est **enregistré automatiquement** (le message « ✓ Brouillon enregistré » s'affiche en haut). Vous pouvez commencer avant l'entretien et terminer après.
4. Pendant l'entretien, le bouton **« Mode entretien (plein écran) »** masque tout le reste.
5. Obligatoire pour viser : date de l'entretien, les 15 critères de la partie III, au moins un objectif individuel et l'appréciation générale. L'encadré jaune en bas de page indique ce qui manque.
6. Cliquez sur **« Je vise le compte rendu et le transmets »**. Le compte rendu n'est plus modifiable et part à l'agent.

**L'agent est à côté de vous au moment de son visa ?** Dans le panneau de droite, cliquez sur **« Faire viser l'agent sur ce poste »**. L'agent saisit lui-même ses observations et son code personnel.

---

## 4. N+2, N+3, direction, DGS – visas

- Vous voyez dans **« Mon équipe »** tous les comptes rendus de votre ligne hiérarchique, avec leur avancement.
- Quand c'est votre tour : ajoutez vos observations éventuelles, cochez la case, puis **Viser**.
- **Une correction de fond est nécessaire ?** Cliquez sur **« Renvoyer en rédaction »** et indiquez le motif. Le N+1 est prévenu, il corrige, et **le circuit recommence depuis le début** : les visas déjà posés sont annulés, car le contenu change.

## 5. Espace RH (administrateurs)

Menu **Espace RH ▾** en haut de l'écran.

### 5.1 Préparer une campagne (une fois par an, en octobre)

1. **Campagnes → Nouvelle campagne** : année, dates, délai de relance.
2. Dans la campagne, saisissez les **objectifs généraux de la Ville**, puis ceux de chaque **direction et pôle**. Ils apparaîtront automatiquement dans la partie IV de chaque compte rendu.
3. **Imports → ① Base agents** : déposez l'export agents Inser/Ciril (.xlsx ou .csv, tel quel).
   - Les agents sont mis à jour par matricule. Vous pouvez réimporter autant de fois que nécessaire.
   - Un agent dont la **date de départ** est passée est désactivé.
   - Seules les colonnes utiles sont lues. **Salaires, adresse et date de naissance ne sont jamais enregistrés.**
4. **Imports → ② Circuits de visas** : déposez le fichier « Acteurs du workflow (Entretien) », dans le même format qu'Inser.
   - Un dossier est créé par agent, avec son circuit, et les objectifs de l'an dernier sont repris.
   - Les **points à vérifier** s'affichent : circuit qui ne finit pas par l'agent, personne présente deux fois de suite, matricule inconnu…
5. **Agents & circuits → Imprimer les codes provisoires** : une fiche à découper par agent (matricule + code), filtrable par direction. À distribuer aux agents sans e-mail.

### 5.2 Suivre la campagne

- **Tableau de bord** :
  - avancement global et par direction ;
  - **« Qui bloque ? »** : les personnes qui ont des dossiers en attente depuis trop longtemps ;
  - besoins de formation, souhaits de mobilité, recours ;
  - répartition des appréciations par critère.
- **Tous les dossiers** : filtres (étape, direction, en retard, recherche). Cochez des dossiers puis cliquez sur **« Relancer la sélection »**.
- **E-mails** : l'historique de tout ce qui a été envoyé (ou seulement enregistré si l'envoi n'est pas configuré).

### 5.3 Cas particuliers

| Situation | Que faire |
|---|---|
| Un N+1 est parti ou absent | **Agents & circuits → l'agent → « Changer le rédacteur »** (pendant la rédaction) |
| Un N+2 ou une directrice est parti(e) en cours de circuit | Fiche de l'agent → circuit → **Remplacer** la personne (seules les étapes non visées sont modifiables) |
| L'agent a signé sur papier | Ouvrir le dossier → **« Enregistrer un visa papier »**, avec la date de la signature |
| Nouvel agent arrivé en cours de campagne | Fiche agent → composer le circuit → **« Créer le dossier »** |
| Agent qui a oublié son mot de passe | Fiche agent → **« Générer un nouveau code »** |
| Demande de révision ou recours | Dossier terminé → **« Demande de révision / recours »** : dates, décision, CAP. Si la révision est acceptée : **« Rouvrir le dossier »** |
| Donner l'accès RH à une collègue | Fiche agent → cocher **« Administrateur RH »** |

### 5.4 Exports

- **Comptes rendus PDF (zip)**, filtrable par direction et par collectivité. L'archive est **déjà rangée comme le serveur** : `Ville` ou `CCAS` / `Titulaire`, `Contractuel`… / `NOM Prénom - EP 2026.pdf`. Il suffit de copier son contenu dans *sjr / drh / communs / entretiens pro*.
- **Excel** :
  - suivi de campagne ;
  - besoins de formation, pour le plan de formation ;
  - vœux, mobilité et carrière ;
  - appréciations.

Le PDF d'un compte rendu terminé est **figé au dernier visa** : il ne changera plus, même si le modèle évolue.
